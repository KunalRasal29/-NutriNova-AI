# Nutrition Data Sources

NutriNova AI stores provenance for every imported, user-entered, or estimated nutrition value. Each source includes a source type, citation, license fields, source URL, reliability score, and active flag.

Important public references for future importers:

- USDA FDC API: https://fdc.nal.usda.gov/api-guide/
- USDA FDC downloads: https://fdc.nal.usda.gov/download-datasets/
- Open Food Facts API: https://openfoodfacts.github.io/openfoodfacts-server/api/
- Indian Nutrient Databank: https://www.anuvaad.org.in/indian-nutrient-databank/

AI-estimated and user-entered nutrition values must remain visibly marked as estimates and should not overwrite verified source values.
